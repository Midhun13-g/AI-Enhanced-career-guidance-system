# AI-Enhanced Career Guidance System

A full-stack application that combines a React frontend, Spring Boot backend, Python AI service, and PostgreSQL database to provide AI-powered career guidance.

## Supabase database setup

The backend uses Supabase PostgreSQL through the datasource settings in [backend/.env](backend/.env) and [backend/src/main/resources/application.yml](backend/src/main/resources/application.yml).

Replace `YOUR_SUPABASE_DATABASE_PASSWORD` with the actual database password from your Supabase project.
